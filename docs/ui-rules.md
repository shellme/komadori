# コマドリ 画面の部品と並べ方の決まり

画面の言葉・部品・並べ方について、コマドリで決めたことを書く。

## 言葉
| 意味 | 使う言葉 |
|---|---|
| つくった1つ1つ | **日程調整**（「この日程調整を削除」「この端末で見た日程調整」）。「調整」だけにしない（△の「調整が必要」とまぎれるため） |
| 新しくつくる | **日程調整をつくる**（見出し・フッター・使い方）、ボタンは「つくる」 |
| 質問に答える | 回答する |
| 回答・入力を変える | 変える |
| 設定を変える | 設定を編集 |
| 日程調整をなくす | 削除 |
| 入力を空にする | 消す |

## 選ぶ部品
| 何をしたいか | 部品 | 例 |
|---|---|---|
| フォームの中で値を1つ選ぶ | ラジオボタン（○ の印・行全体が押せる） | 時間の刻み、まとめて入力の「入れる日」 |
| フォームの中で当てはまるものを複数選ぶ | チェックボックス（□ の印） | 集まりたい長さ |
| 見え方だけを切り替える（保存しない） | 切り替え（灰色の溝で選んだものを白く） | 未回答／すべて |
| 画面の主なモード | 大きな切り替え（黒で塗る） | 自分の時間を回答／みんなの状況 |
| 結果をしぼる・並べる | 選択リスト（「条件」の中） | 集まりたい長さ・対象の日・参加できる人数・並べ方 |
| 押して切り替える名前の一覧 | チップ（押すと ✓） | 必須の人 |

## ボタンの並べ方
- **1つのまとまりに主な操作（ピンクの塗り）は1つだけ**。その場で一番やってほしいこと
- **画面・カードの中**：左寄せ。主な操作（よく使うもの）を先に、ほかを後に。**消す・取り消す操作は右端に離す**
  - 例：日のカードの［まとめて］……［× 参加不可］
- **フォームの最後の確定（つくる・保存する）**：ダイアログの下と同じく、区切り線の下で右寄せ
- **ダイアログの下**：区切り線の下で右寄せ。**［やめる］［主な操作］の順で、主な操作がいちばん右**。**消す操作は左端に離す**
  - 例：［入力をまとめて消す］……［やめる］［まとめて入れる］、［この日程調整を削除］……［やめる］［保存する］
- 消す操作は赤い枠のボタン。取り返しのつかないものは2回押しで確定（「本当に〜」）
- 部品は `.actions`（並び）、`.actions.dlgfoot`（ダイアログの下）、`.danger`（消す操作）を使う

## 管理の操作
- 管理用の URL で開いたときだけ、点線の枠（管理）に［⚙️ 設定を編集］［📍 場所の空き状況］を出す
- 編集・貼り付けはダイアログで開く（どこまでが操作の範囲かわかるように）

## 説明の文字（補足・注意・情報）
| 目的 | 見た目 | 例 |
|---|---|---|
| **補足**：何を書くか・どう使われるか・今の状態の案内 | 欄のすぐ下か見出しの横に、小さい灰色の文字（`.info`・`.sub`）。**印は付けない**。2行まで。長い説明は使い方のページへのリンクにする | 時間の刻みの説明、使わない日の書き方、名前の欄の案内 |
| **注意**：知らずに進むと困ること | 線の「!」の印（アイコン）＋太字（`.warn`）。取り返しがつかないものは赤（`.warn.danger`）。1つのまとまりに1つまで | 管理用 URL を人に送らない（赤）、必須の人がまだ回答していない |
| **情報**：その日・その枠のこと（説明ではない） | ふつうの1行（`.dayinfo`） | 使わない時間あり：別のライブ |
| **使い方のページの本文** | 本文の文字。印も灰色もなし | 「押したらその場で保存します」 |

- 文字の「ⓘ」は使わない（小さいと①に見えて読めない）。印が要るときは線の印（アイコン）で描く
