コマドリ

使い方・よくある質問

コマドリは、みんながそろう「コマ（時間の枠）」を見つける日程調整です。ログインはいりません。

呼びかける人回答する人場所の空き状況の形よくある質問

呼びかける人

  1. 日程調整をつくる：トップで名前・期間（3か月まで）・対象の日（すべて／土日祝だけ／平日だけ）・1日のうちの時間・集まりたい長さを入れます。使わない日や時間帯、呼びたい人（先頭に * で必須）も入れられます。
  2. URL を送る：「回答用の URL」を LINE などで送ります。「管理用の URL」は自分だけで取っておきます（この端末にも覚えます）。
  3. みんなの状況を見る：日ごとに、何人そろうか・★ 候補（よい時間帯）が出ます。「条件」の集まりたい長さ・対象の日・参加できる人数・必須の人・場所のグループでしぼれます。いちばん上の「週ごとのいちばんよい枠」で、週に1回ずつ選ぶときの候補を見比べられます。
  4. 場所の空き状況を貼る（任意）：管理用の URL で開くと、スタジオ・お店などの空き状況を貼れます。候補ごとに空いている場所が出ます。
  5. 決めて知らせる：候補を見て日時を決めたら、管理用の URL の候補にある「文面をコピー」で、LINE などに貼って知らせます（決めた日時はこのアプリには記録しません）。

回答する人

  1. 名前を入れる：送られてきた URL を開き、名前を入れるか、一覧から自分の名前を選びます。
  2. 空いている時間を選ぶ：日ごとに並んだ時間のマスを押します。押すたびに 空き → ● 参加できる → △ 調整が必要 と変わります。パソコンはなぞると続けて入ります。
  3. まとめて入れる：「まとめて」の 昼・夜 のボタンや、「⚡ まとめて入力」で曜日ごとにまとめて入れられます。1つの曜日に時間帯をいくつでも足せます（例：10〜21時は参加できる、9〜10時と21〜22時は調整が必要）。あとから1日ずつ変えられます。
  4. 行けない日：「× 参加不可」を押します。ひとことは ⋯ の「コメントを書く」から。

押したらその場で保存します。保存ボタンはありません。

場所の空き状況の形

スタジオ・お店・会議室など「場所ごとに、空いている時間」を、次の4つのどれかで貼ります。形はアプリが見分けます。管理用の URL で開き、［📍 場所の空き状況］から貼ってください（.txt・.csv・.json のファイルも、読み込むか、パソコンなら枠に落として入れられます）。

1. 1行に1つ（手で書くとき）

「場所・日付・空いている時間」をタブで区切ります。4つめからはメモ（広さ・人数など）。メモの中の「4〜8人」「〜6人」は、その場所の人数として読みます。http で始まるものは予約ページのリンクになります。

スタジオA 32帖	12/5	13:00-18:00, 19:00-22:00
スタジオA 32帖	12/6	10:00-12:00
居酒屋まる	12/5	18:00-23:00	4〜8人	https://example.com/maru

タブがないときは「場所 日付 時間帯」を空白で区切って読みます（例：会議室B 12/7 9:00-12:00）。場所の名前に空白があるときはタブを使ってください

2. 表（縦長・スプレッドシートからコピー）

1行目を見出しにします。見出しの名前で列を見分けるので、列の順番は自由です。タブ区切り・カンマ区切りのどちらでも読めます。

場所	日付	空き	メモ	URL	グループ	人数
スタジオA	2026/12/5	13:00-18:00 / 19:00-22:00	32帖	https://example.com/a	新宿	7〜12人
スタジオB	12/6	10:00-12:00	20帖		代々木	3〜6人
  • 場所（必須）：「店」「部屋」「スタジオ」でも可
  • 日付（必須）・空き（必須）：「空き時間」「時間」でも可
  • メモ（「備考」）・URL（「リンク」）・グループ（「エリア」「駅」「店舗」）・人数（「適正人数」「定員」）は任意。グループは結果で場所をしぼるのに、人数は候補に人数に合う場所を先に出すのに使います

3. 表（日付×場所の横長）

1行目の1列目を「日付」にし、2列目から場所を並べます。「グループ」「URL」「メモ」「人数」の行を入れると、その列の場所の情報になります。

日付	スタジオA 32帖	スタジオB 20帖
グループ	新宿	代々木
URL	https://example.com/a	https://example.com/b
2026-12-05	13:00-18:00 / 19:00-22:00	受付前
2026-12-06	10:00-12:00	×

空きがない日は、空欄・「×」「-」「受付前」「満」「満室」「なし」のどれかにします

4. JSON（ほかのツールから渡すとき）

{
  "format": "availability",
  "version": 1,
  "asOf": "2026-11-11T09:00:00+09:00",
  "places": [
    { "id": "a32", "name": "スタジオA 32帖", "group": "新宿", "capacity": { "min": 7, "max": 12 }, "note": "ドラム2台", "url": "https://example.com/a" }
  ],
  "slots": [
    { "place": "a32", "date": "2026-12-05", "free": ["13:00-18:00", "19:00-22:00"] }
  ]
}

place は places の id（なければ name でも可）。capacity はその場所の人数（任意。min・max の片方だけでも可）。asOf は「いつ時点の空き状況か」で、結果の画面に「11/11 9:00時点」のように出ます

共通の決まり

  • 時刻は24時間で「13:00」の形（「9:00」も可）。日をまたぐときは「22:00-26:00」のように24時より先も書けます
  • 時間帯の区切りは「-」「〜」「~」「–」のどれでも。複数は「,」「、」「/」「／」で区切ります
  • 日付は「2026-12-05」「2026/12/5」「12/5」。年がなければ日程調整の期間から決めます。期間の外の日は使いません
  • 日程調整の刻み（30分か1時間）に合わせて丸めます（始まりは切り上げ、終わりは切り捨て。例：30分刻みで 13:10-15:50 → 13:30-15:30）
  • 場所の名前に「32帖」のような広さがあれば、メモにも入れます
  • 読めない行は、何行目か・なぜかを出して飛ばします（ほかの行は使います）
  • 人数は任意です。人数のある場所は、候補の時間に来られる人数（調整が必要な人も入れる）に合う場所を先に出し、人数より大きい場所は「広め」として後ろに出します。人数が入りきらない（上限より多い）場所は数だけ出します。人数のない場所は、どの人数の候補にも出します

AI に作ってもらうときの指示

予約サイトの空き状況のページやスクリーンショット、メールなどを AI（ChatGPT・Claude など）に渡して、貼れる形に直してもらえます。下の指示をコピーし、［　］を書きかえて、空き状況の情報と一緒に送ってください。できた表をそのまま貼れます。

次の空き状況の情報を、日程調整ツール「コマドリ」に貼れる表に直してください。

# 出してほしい形
- タブ区切りの表。1行目は見出しで「場所	日付	空き	メモ	URL	グループ	人数」
- 1行に「1つの場所の1日分」
- 日付は YYYY-MM-DD（例：2026-12-05）
- 空きは 24時間の「HH:MM-HH:MM」。空いている時間帯が複数あるときは「, 」で区切る（例：13:00-18:00, 19:00-22:00）
- 日をまたぐときは 24時より先で書く（例：22:00-26:00）
- 空きがない日は行を出さない
- メモには広さ・人数・値段など、場所を選ぶのに役立つことを短く。わからなければ空欄
- URL は予約ページがわかれば。わからなければ空欄
- グループには店舗名・駅・エリアなど、場所をまとめる名前。わからなければ空欄
- 人数にはその部屋の適正人数を「3〜6人」「〜6人」の形で。わからなければ空欄（推測で埋めない）
- 表だけを出し、前後の説明は書かない。コードブロックに入れる

# 条件
- 期間：［2026-12-01］〜［2026-12-31］の日だけ
- 時間：［9:00］〜［23:00］の間だけ（それより外は切る）
- 場所：［例：スタジオAとスタジオBの 20帖以上の部屋だけ］
- 読み取れない・あいまいなところは、推測で埋めずに表の後ろに「確認が必要：…」と1行で書く

# 空き状況の情報
［ここに予約サイトの表・メール・スクリーンショットの内容を貼る］

よくある質問

ログインや会員登録はいりますか？

いりません。URL を知っている人なら誰でも見て回答できます。そのため、日程調整の URL は呼びたい人だけに送ってください。

前に入れた回答を変えたい／別のスマホから変えたい

同じ端末なら、開くと自分の回答がそのまま出ます。別の端末からは、名前の一覧で自分の名前を選ぶと変えられます。誰がどの端末で変えたかは記録に残ります。

管理用の URL をなくしてしまいました

日程調整をつくった端末なら、トップの「この端末で見た日程調整」に「つくった日程調整」として残っています。ほかの端末からは取り出せないので、作ったらメモなどに残しておいてください。

30分刻みと1時間刻みのどちらがいいですか？

はじめは1時間になっています。スタジオのように30分単位で取れる場所なら30分、ざっくり決めたいなら1時間がおすすめです。刻みはあとから「⚙️ 設定を編集」で変えられます。

1つの日程調整は何人まで使えますか？

回答できるのは100人まで、呼びたい人の一覧も100人までです。快適に使える目安は50人くらいまでです（人数と期間が多いほど、みんなの状況の計算に時間がかかり、スマホでは表示が少し遅くなります）。それより大人数のときは、グループごとに日程調整を分けるのがおすすめです。

あとから設定を変えられますか？

管理用の URL の「⚙️ 設定を編集」で、つくるときに決めたことはすべて変えられます。期間や1日の範囲を縮めても回答は消えません（外になったところは出なくなるだけで、元に戻せばまた出ます）。30分刻みを1時間刻みにすると、回答は1時間に丸めて数えます（変える前に、何人の回答が丸まるかを知らせます）。

「必須の人」とは？

その人が来られない時間は候補に出さない人です。△（調整が必要）の時間は、来られるとして数えます。呼びたい人の名前の先頭に * を付けるか、みんなの状況の「必須の人」で選びます。

「優先する人」とは？（来られる日が少ない人に合わせたい）

その人が来られる枠を、人数より先に上へ出す人です。来られない日も消さずに、ほかの人の人数で並べます。必須の人とちがい、来られない日の候補もなくなりません。

その人の時間に一部だけ重なる枠（例：その人は 13:00〜15:00、枠は 14:00〜16:00）は「一部の時間だけ」と出し、重ならない枠より先にします。「やっぱり行けるかも」となったときに合わせやすい枠です。

その人1人だけの枠が上に来るときは、「参加できる人数」で少ない枠を外してください。選んだ人は、この端末にこの日程調整ごとに覚えます。

広い部屋を先に出したい

場所の空き状況を貼っているときは、「条件」の「場所の並べ方」で「広い順」を選ぶと、人数に合うかどうかより広い部屋を先に出します。遠くから来る人がいる日に、来やすい町のグループと合わせて使えます。

場所の空き状況はどんな形で貼れますか？

1行に1つ・表（縦長）・表（日付×場所）・JSON の4つです。くわしくは場所の空き状況の形を見てください。AI に作ってもらうための指示も載せています。

祝日はどう扱いますか？

日本の祝日を初めから入れてあり、土日と同じに数えます。使わない日・時間帯に曜日や「平日」で書いたものは、祝日にはかかりません（祝日も外したいときは 月 水 祝 のように「祝」を足します）。

土日祝だけで日程調整できますか？

できます。日程調整をつくるときの「対象の日」で「土日祝だけ」を選びます（「平日だけ」もあります）。あとから管理用の URL の「⚙️ 設定を編集」でも変えられます。

月によって対象の日を変えられますか？（1月は土日祝だけ、2月は全部など）

できます。対象の日は「すべての日」のままにして、使わない日・時間帯に 1月 平日 と書きます。1行に「いつ（12/24・1/1-1/5・1月）」「どの日（平日・土日・月 水 など）」「何時（9:00-18:00）」「ひとこと」を、要るものだけ並べて書けます。

日程調整はいつまで残りますか？

期間の終わりから90日たつと、回答ごと自動で消えます。管理用の URL の「この日程調整を削除」で、すぐに消すこともできます。

お金はかかりますか？

かかりません。

不具合や要望、回答を消してほしいときは？

日程調整ごと消すときは、管理用の URL の「この日程調整を削除」から消せます。自分の回答は、「⚡ まとめて入力」の「入力をまとめて消す」か、日ごとの ⋯ の「この日の入力を消す」で消せます。名前ごと消してほしいときや、不具合・要望は、GitHub の Issues から知らせてください（GitHub のアカウントが要ります）。
